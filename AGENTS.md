# Regras do projeto

- Criar um site de portfólio pessoal usando HTML, CSS e JavaScript puro, sem frameworks.
- Antes de criar ou alterar qualquer arquivo, ler referencias.md, identidade.md e funcionalidades.md.
- Seguir as referências visuais escolhidas, sem copiar os sites.
- Manter o código organizado, com HTML, CSS e JavaScript em arquivos separados.
- Utilizar nomes de classes e variáveis claros.
- Criar um layout moderno, original e profissional.
- Garantir que o site funcione em computadores, tablets e celulares.
- Não utilizar imagens quebradas ou links inexistentes.
- Garantir que os botões, menus e formulário funcionem.
- Utilizar animações suaves e sem exageros.
- Não criar funcionalidades desnecessárias.
- Após cada etapa, explicar brevemente o que foi desenvolvido.
- Testar o site e corrigir possíveis erros antes de finalizar.
